# きらるわけ

キラル分子を **R体(右の箱)** と **S体(左の箱)** に仕分けるブラウザゲーム。
パスツールが1848年にピンセットで酒石酸塩の結晶を仕分けた話がモチーフ。

▶ プレイ: https://stsuruga.github.io/kiraru-wake/

## ルール
- **S・M(左回り / 左巻き)→ 左の青い箱**、**R・P(右回り / 右巻き)→ 右のオレンジの箱**
- キラリティーは4種類:中心性(R/S)・軸性(Ra/Sa)・面性(Rp/Sp)・らせん(P/M)。時間経過で種類が増える
- メソ体 → 中央の小さい箱へ。入れた瞬間に温度ルーレット(❄冷却60% / 🔥加熱40%)。すばしっこく、放置すると消える
  - メソ箱は当たり判定なし。キラル分子は入らない
- 🔥 360 K 超でランダムな分子のキラリティーが反転(アレニウス式で熱いほど速い)/ ❄ 冷却で分子がゆっくり
- 箱が25分子で回収 → 「回収済み」に加算。箱をまちがえるとその箱の中身は光学純度低下で集計から除外
- 赤いリングで点滅している分子は放置しすぎ。時間切れでアウト
- 60秒で下のゲートが開き、出現口が2つに
- 分子図鑑:仕分けた分子(18種)が登録され、説明と鏡像ペアが見られる
- モード:やさしい(色+記号+優先順位)/ふつう(色+構造)/ガチ(構造のみ)
