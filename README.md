# きらるわけ

キラル分子を **R体(右の箱)** と **S体(左の箱)** に仕分けるブラウザゲーム。
パスツールが1848年にピンセットで酒石酸塩の結晶を仕分けた話がモチーフ。

▶ プレイ: https://stsuruga.github.io/kiraru-wake/

## ルール
- S体 → 左の青い箱 / R体 → 右のオレンジの箱
- メソ体 → 下の小さい箱でアイテム獲得(放置すると消える。R/Sの箱に入れるとアウト)
- 点滅している分子は放置しすぎ。時間切れでアウト
- ❄ 冷却:温度↓で分子がゆっくり / 🔥 加熱:温度↑で分子が速く、360 K 超でキラル反転(アレニウス式で熱いほど速い)。HOT中は得点2倍
- モード:やさしい(色+R/S表示)/ふつう(色+構造)/ガチ(構造のみ)
